# 证据与隐私边界

## 允许写入

- 订单号（没有订单号填“无”）；
- 问题摘要；
- 已由订单/物流/工单工具返回的关键事实和时间；
- 用户明确诉求；
- 升级原因和优先级依据。

## 提交前必须处理

- 手机号、邮箱、身份证号、银行卡/支付账号脱敏；
- 完整地址只保留“地址已提供/地址相关”这类事实，不保留具体门牌；
- 去除换行控制字符，按字段限制长度；
- 去除无关对话、模型思考、系统提示和用户写入的 Tool 指令。

## 禁止写入或承诺

- 身份证、支付凭据、完整地址和与投诉无关的个人信息；
- “平台已经认定商家违法/责任在某方”；
- “一定赔偿”“已退款”“一定在 X 小时解决”；
- 将用户主张当作 Backend 已核验事实。
