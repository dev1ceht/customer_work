# 物流政策快照

- policyVersion: `logistics-policy-2026-01`
- owner: 客服履约与物流运营
- effectiveFrom: `2026-01-01`
- reviewCadence: 每季度，或物流供应商/承诺时效规则变更时

## 可追溯规则

| ruleId | 规则 | Agent 行为 |
|---|---|---|
| LOGISTICS-001 | 订单号和订单状态以订单 Backend 结果为准 | 先查订单，不猜订单 |
| LOGISTICS-002 | 物流阶段和轨迹以物流 Backend 结果为准 | 只复述返回事实 |
| LOGISTICS-003 | 没有最近更新时间或新鲜度证据 | 不判断是否按时；涉及延误时人工升级 |
| LOGISTICS-004 | 状态未知、轨迹缺失、明确过期或签收争议 | 标记物流异常并转人工 |
| LOGISTICS-005 | 没有明确承诺时效依据 | 不估算 ETA，不承诺到达时间 |
| LOGISTICS-006 | 查询不可用或结果不确定 | 不伪造轨迹，转人工或请用户稍后查询 |

## 口径

“已发货/运输中/派送中/已签收”是物流阶段，不是对时效或责任的判断。“信息未知”不能回答为“正常运输”。
