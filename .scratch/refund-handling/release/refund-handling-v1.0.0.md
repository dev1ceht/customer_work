## 回滚边界

回滚必须恢复完整的 Skill、政策、Tool 契约、Backend 和数据库兼容组合；数据库只前进不回退，历史退款、审批、冻结和审计记录不得删除。

本版本仍只支持已支付、未发货订单的全额仅退款；部分退款、退货退款、换货和未支付取消不在范围内。
